## Selected projects

### ManoCad — gesture-controlled 3D modeling
**Python · OpenCV · MediaPipe · NumPy**

A desktop CAD prototype that turns hand gestures into editable 3D geometry and STL exports for 3D printing. It brings together hand tracking, gesture state machines, unit conversion, compound geometry, void cuts, and project persistence.

The gesture layer uses MediaPipe landmarks and geometric rules. Tests cover geometry, units, attachments, project files, and STL handling. Source is currently private.

### Pneuma — prayer, goals, and community
**Flutter · Dart · Firebase Authentication · Cloud Firestore**

A community app for prayer requests, goals, and Circle chat. The current beta includes account flows, feed search, hashtags, mentions, notification preferences, and light/dark themes.

The project includes database access rules, app/session tests, and web release tooling. Source is currently private.

### Wordle for family and friends
**JavaScript · HTML/CSS · Firebase Realtime Database**

I extended an existing Wordle project for my grandparents, adding online rooms, word definitions, scoring, and result boards. The current multiplayer flow supports two players.

**[Play Wordle](https://benjaminsprankle.github.io/wordle_clone/) · [Explore the fork and attribution](https://github.com/BenjaminSprankle/wordle_clone)**
